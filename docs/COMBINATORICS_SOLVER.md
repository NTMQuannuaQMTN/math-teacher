# Combinatorics solver status

Combinatorics is now a first-class topic (`combinatorics`). A valid solution must identify the objects, distinguishability, order, repetition, restrictions, case coverage, and overlap before presenting a count. Inclusion-exclusion and complementary counting must state the sets being combined.

The existing deterministic infrastructure can validate small finite claims when encoded as answer checks or exhaustive fixtures. It must not turn a small-instance brute-force result into a general proof. A general outcome-model checker and teacher-reviewed combinatorics corpus remain planned.
