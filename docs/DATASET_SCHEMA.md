# Chuyên dataset: schema and pipeline

Dataset `chuyen-v1`. Everything under `data/` except `data/exams/{raw,pages,text}` is generated by
`tools/exams/build_dataset.py` from `tools/exams/catalog.py`. To change the data, edit the catalog (or
`teaching.py`) and rebuild; never edit generated files.

## Pipeline

```
source PDF (data/exams/raw, gitignored)
  → render pages (PDFKit, scratchpad render.swift → data/exams/pages)   text layers are unusable for formulas
  → transcription into tools/exams/catalog.py (Claude, from page images; ocr_status = transcribed_needs_review)
  → independent verification (tools/exams/verify_exams.py → data/exams/verification.json)
  → build (tools/exams/build_dataset.py) → data/… + tools/benchmark/dataset/chuyen.jsonl
```

```bash
python3 tools/exams/verify_exams.py && python3 tools/exams/build_dataset.py
python3 tools/exams/query_knowledge.py stats
```

## Files

| File | One record per | Purpose |
|---|---|---|
| `data/exam_sources.json` | source document | provenance: URL, type, access date, SHA-256, licence notes, local file |
| `data/exams/<exam_id>.json` | exam | metadata + its questions |
| `data/processed/problems.jsonl` | problem (sub-question) | the normalised problem record |
| `data/knowledge/profiles.jsonl` | problem | knowledge profile (concepts, techniques, insight, level) |
| `data/knowledge/graph.json` | concept / technique | index: concept → problems, technique → problems and co-occurring concepts |
| `data/techniques/taxonomy.json` | concept / technique | names, levels, prerequisite edges |
| `data/{training,validation,test}/problems.jsonl` | problem | split files (problem + profile) |
| `data/training/teaching.jsonl` | verified training problem | teaching record (training target) |
| `tools/benchmark/dataset/chuyen.jsonl` | problem | solver benchmark item (grading regexes) |

## Problem record (`data/processed/problems.jsonl`)

| Field | Type | Notes |
|---|---|---|
| `problem_id` | string | stable: `<exam_id>/<question number>` (e.g. `ptnk-2024-chuyen/3c`) |
| `exam_id`, `question_number` | string | |
| `school`, `province`, `year` | string, string, int | |
| `topic` | algebra · number_theory · combinatorics · geometry · probability · statistics · word_problem · applied_optimization | coarse; the knowledge profile is the detailed label |
| `kind` | solve · compute · prove · construct | what the answer is |
| `stem` | string \| null | shared stem of a multi-part question, kept separate from the part |
| `question` | string | the sub-question's original Vietnamese wording, LaTeX in `$…$` |
| `problem_text` | string | `stem + question` (what a solver receives) |
| `diagram` | string \| null | set when the statement depends on a figure; how the figure's information is captured |
| `official_answer` | string \| null | the source's final answer (null if none was obtained) |
| `answer` | string | answer used for grading ("proof" for proofs) |
| `answer_status` | official · teacher · derived | |
| `verification` | string \| null | check id in `verify_exams.py` (or `ground_truth.py:<id>`); null = manual review |
| `source_id`, `page` | string, int | |
| `split` | train · validation · test | |
| `ocr_status` | transcribed_needs_review · verified_in_benchmark | |

## Knowledge profile (`data/knowledge/profiles.jsonl`)

```json
{
  "problem_id": "ptnk-2024-chuyen/3c",
  "knowledge": [{"concept": "nt.modular_arithmetic", "name": "Đồng dư, xét số dư", "role": "prerequisite", "level": "specialized_grade9"}],
  "techniques": [{"technique": "tech.periodicity_mod", "name": "Tính tuần hoàn theo modulo", "role": "main"}],
  "key_insight": "Every a_n is even, so only divisibility by 7 matters; the residues mod 7 are periodic.",
  "difficulty": 3,
  "expected_level": "specialized_grade9",
  "alternative_methods": [], "common_errors": [],
  "annotation_status": "claude_annotated_needs_teacher_review",
  "solution_verified": "official_key+computed"
}
```

`difficulty` 1–5 measures reasoning demand (1 = one standard step; 5 = several non-obvious ideas), not the
exam's reputation. `expected_level`: `standard_grade9` (lớp 9 textbook), `specialized_grade9` (chuyên
enrichment a chuyên student is expected to know), `olympiad_style` (needs an insight beyond regular
chuyên training).

## Teaching record (`data/training/teaching.jsonl`)

`problem_type` (Nhận dạng), `required_knowledge`, `key_idea`, `hints[]` (from light to explicit), `solution[]`
(short steps, LaTeX), `final_answer`, `takeaway` (reusable lesson), `techniques`, `expected_level`,
`verification`, `author`, `review_status`. Written from the verified answer and the annotation, not copied
from the answer keys.

## Splits and leakage

The split is by **exam** (source-level): every sub-question, stem and solution of an exam is in exactly one
split. There are no synthetic variants. The PTNK 2026 chuyên items appear once (as `ptnk-2026-chuyen/*`,
identical to the benchmark's `ch-1 … ch-5`), in validation in both places.

| Split | Exams | Rationale |
|---|---|---|
| train | PTNK 2023, 2024, 2025 | past papers of one school |
| validation | PTNK 2026 chuyên, TP.HCM 2025 | a newer year, and another board in the same city |
| test (held out) | Hà Nội 2025, KHTN 2025 vòng 2 | unseen region and boards: tests generalisation |
